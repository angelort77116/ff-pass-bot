# FF Pass Bot

Bot de WhatsApp para envio automatico de parcela/passe de Free Fire.

## Numeros

- Bot conecta em: `556593511752`
- Dono do bot: `5569993841805`

## Comando do cliente

```text
/passe+ID
```

Exemplo: `/passe+123456789`

O bot responde automaticamente com o pedido, valor e chave PIX.

## Painel do dono

PIN padrao: `1805`

No WhatsApp do dono, envie `/dono` para o menu tradicional:

1. Alterar valor do passe
2. Alterar nome do passe
3. Alterar chave PIX
4. Alterar nome PIX
5. Ligar/Desligar bot
6. Ligar/Desligar envio automatico
7. Ver pedidos
8. Ver configuracoes
9. Alterar PIN do painel

## Como ligar

```bash
npm install
npm start
```
